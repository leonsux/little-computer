# 🌈 小小电脑家

给 4 岁左右孩子玩的电脑启蒙游乐场。V0.1 通过简单小游戏练习鼠标移动、点击、拖动和自由创作。

## 当前状态

第一轮已实现：

- 首页入口
- 「点星星」游戏
- 「水果篮」拖动游戏（四级难度）
- 家长页面：本地统计、今日时长和游戏设置
- 「小画家」：自由绘画、颜色、画笔、橡皮擦、保存和作品展示
- 20 颗星星完成流程
- 本地游玩次数记录
- 轻量 Web Audio 音效
- 游戏完成页的「再玩一次」「回家」

## 运行

无需安装依赖，直接双击 `index.html`，或在项目目录启动任意静态文件服务器后访问。
