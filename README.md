# 小小电脑家

面向约 4 岁儿童的离线电脑操作启蒙项目。用游戏练习鼠标移动、定位、单击和拖放，主要面向配有鼠标的电脑。

## 首页与玩法

首页用花园、星空、野餐和画室四个绘本场景作为主要入口，下方「再去探索一下」提供泡泡海洋、翻翻乐和形状小火车，共七个游戏。整块场景都可点击，也可通过 Tab 和 Enter 进入；返回首页后，焦点回到刚才的游戏，并滚动到可见位置。声音开关在首页与所有游戏之间同步。

- **鼠标小花园**：四种练习串成小花成长的故事。移动鼠标唤醒种子，停稳让蝴蝶落下，点击让花苞开放，拖动水壶给花浇水。每种练习照顾三盆花，可以顺序游玩或直接选择任意练习；画面中的小花图标显示当前完成情况。
- **点星星**：所有星星的位置和图案轮廓始终可见，当前要点击的星星带有亮色圆圈。每次点击保留已点亮的星星并连上线，完成后图案轮廓亮起。小三角、小风筝、小房子、小鱼儿、小爱心、小树、小火箭和小花朵由简到难循环；图案在不同窗口宽度下保持比例。
- **水果篮**：为小兔准备野餐，依次练习近距离送一个、重复送几个、送远一点和按图案分类。可以直接选择已启用的练习；拖错、取消或拖动途中调整窗口都会回位，错误分类不会显示可接收的高亮。完整完成本次启用的练习后才记录一轮。
- **小画家**：六色蜡笔、创作参考、可展开的笔刷与橡皮擦、撤销、换白纸确认和作品展示。「找灵感」循环展示小花园、大海和天空参考，「自由画」收起参考；参考与画布分开，不会改动画作或加入导出的图片。草稿在每笔结束后保存在本地，返回、刷新和调整窗口后可继续画；换白纸也可撤销。「看看作品」只展示，点击「导出图片」才下载 PNG。
- **泡泡海洋**：点击泡泡，和里面的小鱼打招呼。已发现的小鱼留在画面里；浅浅海湾、珊瑚花园和彩虹海底分别有 3、4、6 个泡泡，完成后循环探索。泡泡不移动，方便孩子先练习定位再单击。
- **翻翻乐**：翻开两张卡片，寻找相同的小伙伴。由 2 对增加到 3 对、4 对，每次重新打乱位置；找到的朋友保持可见。不同的两张会温和地翻回去，可随时打开「看看提示」显示图片；提示不会替孩子配对，也不记录失败次数。
- **形状小火车**：按住圆形、方形和三角形，送进轮廓相同的车厢，松手后装好。先练习对应位置，再变换车厢顺序，最后加入星形。整个车厢都可接收，形状不匹配、取消拖动或调整窗口时会回位，可重复尝试。
- **家长页面**：算式入口、本地累计完成记录、今日累计时长，以及水果篮启用关卡数量设置。小花园完整完成四种练习后记录一次；记录不代表已独立掌握。

七个游戏共用固定位置的返回入口、声音开关，并提供可重播的图形示范。除自由绘画外，每关完成后会出现烟花和短文案，并在 1.5 秒后自动进入下一关；完成整轮后自动开始新一轮。小花园和水果篮自由选择练习时会接着进入尚未完成的练习。庆祝期间不会重复计完成，返回会立即取消待执行切换。星星、水果篮和三个新游戏也提供「重新玩」。家长页面显示泡泡场景、配对卡组和小火车出发次数，各在完成一关后累计。

移动练习通过光标经过触发；定位练习需要在目标上停稳约 0.7 秒；单击练习必须点击；拖放练习必须拿起并移动，物体中心进入整盆花的目标框后高亮，松开即可放入。水果篮同样使用完整篮子目标框，不限于下半部。示范不计入完成记录，静音时仍有图形提示。

网页使用带白色描边的 56 像素彩色大箭头：移动时为黄色，可点击时为橙色，可拖动时为青色，抓取后为粉色。画板使用中心留空的 48 像素粉色准星，中心即落笔位置。指针仅在网页内容区域生效。

## 运行

无需安装依赖，直接双击 index.html。页面、图形和音效均在本地运行，也可使用任意静态文件服务器访问。

使用原生 HTML、CSS、JavaScript 和内联 SVG；音效由 Web Audio 生成。本地记录和画作草稿使用 localStorage，直接文件模式下由浏览器管理，不同浏览器或不同打开方式的记录可能独立。

草稿存储失败时会在画板旁提示，当前画作仍可查看并导出。清除浏览器数据会影响本地草稿；导出的 PNG 是独立文件。重复查看未修改的作品不会重复增加作品统计。

## 键盘操作

小花园支持 Tab 选择对象、Enter 或空格激活按钮。水壶使用空格或 Enter 拿起和放下，方向键移动，Shift 加方向键微调，Escape 取消。移动与定位练习也提供键盘焦点操作；电脑鼠标技能仍应通过真实鼠标练习观察。

水果篮和形状小火车同样支持空格拿起、方向键移动、空格放下和 Escape 取消，Shift 加方向键微调；点星星、泡泡和配对卡片支持 Enter 或空格点击。画布可通过 Tab 聚焦，使用方向键移动画笔，空格开始或结束画线，Escape 停笔。

## 开发验证

游戏运行不需要 Node.js。浏览器回归脚本位于 tests/，仅供开发验证使用。

验证环境已有 Node.js、Playwright 和 Edge 时，在项目根目录执行：

    node tests/garden.cjs
    node tests/legacy-games.cjs
    node tests/drop-regions.cjs
    node tests/playground.cjs
    node tests/discovery.cjs

脚本默认使用 Windows 标准安装路径下的 Edge；可通过 BROWSER_PATH 指定浏览器可执行文件，通过 NODE_PATH 指定已有的 Playwright 包目录。脚本使用独立的临时浏览器上下文，不操作日常浏览器记录；截图输出到 .tmp/garden-redesign/、.tmp/legacy-games/、.tmp/playground-redesign/ 和 .tmp/new-games/。

脚本覆盖小花园四阶段和成长反馈、水果取消与快速放入、图形分类与练习自由切换、八种星星图案和等比例显示、庆祝期间返回、画作撤销和恢复、创作参考与草稿隔离、预览与导出、存储失败、键盘操作、共享静音、不同窗口宽度、减少动态效果与离线加载。旧版本保存的星星数量设置不再影响图案关卡。

新游戏回归覆盖泡泡单击与场景循环、配对提示和不同图片翻回、重复点击、重玩与离开时取消回调、形状匹配与车厢完整目标框、非中心抓取、窗口变化取消、键盘操作、共享静音、返回入口可见、家长累计记录，以及五种宽度和减少动态效果。

项目规范见 [AGENTS.md](./AGENTS.md)，进度与待验证事项见 [ROADMAP.md](./ROADMAP.md)。
